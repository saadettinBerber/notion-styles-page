# Generate Notion-style pages

Apply the communication principles below to user-facing replies, progress updates,
explanations, and the content you prepare. They are included directly in this skill.
Use the Turkish writing guidance when writing in Turkish.

For page creation, follow the included conversion instructions and consult
`notion-page --help` for CLI options. Give the page enough context for its intended
reader. Let the existing template provide the reading area; focus on the content.

After successful conversion, deliver the output. Only perform post-render checks
when this skill includes the final **Visual verification** section or the user
explicitly requests them. Otherwise, do not reopen or inspect the generated HTML,
launch a browser or preview server, take screenshots, or check themes, phone widths,
or layout. This also applies when consulting the drawing and other syntax guides.

For source-based notes that need an independent factual review, use the separate
`verified-notes` skill. That workflow is not required for ordinary page creation.
